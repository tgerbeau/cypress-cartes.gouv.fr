7 points d'amélioration

1. Contraste de couleurs insuffisant
1 élément ne respecte pas le ratio 4.5:1 (WCAG AA). Vérifier les textes gris clair sur fond blanc.
Impact : serious — WCAG 1.4.3
2. Aucun lien d'évitement (skip navigation)
Les utilisateurs clavier doivent parcourir tous les éléments de navigation avant d'atteindre le contenu principal. Ajouter un lien caché "Aller au contenu" en haut de page.
Impact : serious — WCAG 2.4.1
3. Focus non visible sur les éléments interactifs
Lorsqu'un utilisateur navigue au clavier, aucun indicateur visuel (outline, box-shadow) n'est affiché sur l'élément actif. Ajouter un style :focus-visible.
Impact : serious — WCAG 2.4.7
4. Cibles tactiles trop petites
8 éléments sur 30 (27%) ont une zone cliquable inférieure à 24×24px. Risque d'erreur sur mobile. Augmenter le padding ou la taille des boutons/liens.
Impact : moderate — WCAG 2.5.8
5. IDs dupliqués dans le DOM
5 IDs identiques détectés. Cela peut perturber les lecteurs d'écran et les associations aria-labelledby / aria-describedby.
Impact : moderate — WCAG 4.1.1
6. Pas de fil d'Ariane
La page d'accueil n'expose pas d'indicateur de position dans le site (breadcrumb). Sur les pages intérieures, vérifier la présence d'un fil d'Ariane DSFR.
NNG Heuristique #1 — Visibilité de l'état du système
7. Champ de recherche sans validation HTML5
Le champ de recherche ne comporte pas d'attribut required, pattern ou minlength. Ajouter une validation côté client.
NNG Heuristique #5 — Prévention des erreurs
